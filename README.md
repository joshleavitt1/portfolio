# Josh Leavitt — Portfolio

## Publish

1. Extract this ZIP and copy **all its contents**, including `.github`, into your empty local GitHub repository. `index.html` must be at the repository root.
2. Commit and push to `main` or `master`.
3. One-time GitHub setup: in the repository, open **Settings → Pages**, and set **Source** to **GitHub Actions**. If the first deployment ran before this setting was enabled, rerun the **Deploy website** workflow under Actions.

After that, pushes publish automatically. No installation or build command is required. Supports both `username.github.io` and `username.github.io/repository/` URLs, as well as a custom domain configured in your repository.

## Files

- `index.html` — Results2 homepage and copy.
- `assets/` — only the shared styles, scripts, images, video, fonts, and compiled dependencies used by this site.
- `examples/` — two PIMCO walkthroughs and three email examples.
- `.github/workflows/deploy.yml` — automatic GitHub Pages publication.
- `CREDITS.md` — asset attribution and reference links.

The email apps are already compiled. The larger editable-source archive is a separate handoff; old builds, old projects, local launchers, and unused assets are excluded here.

GitHub Pages setup reference: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
